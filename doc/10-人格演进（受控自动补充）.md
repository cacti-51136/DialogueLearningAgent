# 10 · 人格演进：受控自动补充（PersonaSpec）

> 用户要求：**放开"人格自动更新"的窗口**，但约束必须苛刻——**只在对话累积到一定层次时**，由大模型依据历史对话**推演人格**并**补充**；补充的人格**不能冲突**，且人格描述可覆盖多方向/角度/事件，但**整体规格不超过 200 字**。

## 1. 定位：补一个"软性人格画像"窗口，而非放开规则自动采纳

回顾 doc/02 §11.6：耦合规则（"扳机"）**首期不自动采纳**——因为错规则直接扭曲行为，错了比漏了糟。这扇门保持焊死。

但"人格"不止等于规则。本项目长期价值恰恰在于"AI 越来越懂这个用户"。所以本篇在 §11.6 之外，开一个**更安全的自动窗口**：让 LLM 从累积历史里推演出一段**自然语言人格规格书（PersonaSpec，≤200 字）**，作为 L3 人格段的**软性补充文本**注入，而非新增结构化耦合规则。

**为什么这条路比自动加规则安全：**

- 它产出的是"描述性文本"，不是"扳机"；即便推演不完美，最坏只是提示词略啰嗦，**不会像错规则那样改变行为逻辑**。
- 它天然适合表达"该用户偏 X、事件 Y 后语气应转 Z、禁忌是 W"这类**跨方向/跨事件的软性画像**，正好用自然语言承载。
- 它**永不触碰 `coupling_rules.yaml`**（§11.6 不变）、**永不覆盖 `constraint.safe_mode` 硬约束**（doc/09 §6）。

> 一句话：规则仍锁死在人工审核；人格画像打开一个默认关闭、门槛极高的自动通道。

## 2. 数据结构（PersonaSpec）

```yaml
persona_spec: >                  # ≤200 字自然语言，覆盖多角度/事件
  你是一位对这位用户更松弛的外教：他用词简单但爱穿插网络梗，偏好用例子而非术语；
  上次他因时态受挫后明显更自信，可少纠错多鼓励；忌用说教口吻，忌主动聊政治。
covers: [role, tone, empathy, taboo, event_memory]   # 覆盖的方向标签
version: 3                      # 第几次重建
confidence: 0.82
source_turn: 27                 # 触发推演的轮次
created_at: "2026-08-30T18:00:00"
# deltas（可选，仅建议，仍走审核，绝不自动生效）
deltas:
  - { key: empathy, direction: up, reason: "用户多次表达被理解的需求" }
```

`persona_spec` 是**唯一会随对话自动演进的内容**；`deltas` 只是给人工审核的提示，不自动写入。

## 3. 触发门槛：对话"累积到一定层次"才放行（苛刻约束）

必须**同时满足**全部条件，否则静默跳过（零成本）：

| 条件 | 默认 | 含义 |
|---|---|---|
| `turn >= DLA_PERSONA__MIN_TURNS` | 12 | 远超冷启动(2)与周期(3)，确保有足够历史 |
| `E(user_engagement) >= DLA_PERSONA__MIN_EVIDENCE` | 5.0 | 用户参与度证据强度够高，确认对话有**实质内容**而非寒暄 |
| 距上次重建 `>= DLA_PERSONA__COOLDOWN_TURNS` | 8 | 防抖动，避免人格频繁重写 |
| 自上次重建来 L2 关键维度发生**实质性变化** | — | "有东西可更新"才推演，空转不触发 |
| `DLA_PERSONA__AUTO_UPDATE=true` | false | 总开关，**默认关**——窗口存在但须显式开启 |

> 设计意图：门槛刻意设高。"累积到一定层次"= 轮次够多 **且** 内容够实 **且** 有变化 **且** 已过冷却。任一不满足都不演进，确保人格演进是**罕见、慎重**的事件。

## 4. 推演：LLM 依历史对话进行人格推演

触发后，调用一个**便宜小模型**（可复用 `DLA_LLM__ANALYZER_MODEL`）做一次性结构化推演：

```
system: 你是人格推演器。基于对话历史，为当前用户生成一段 Agent 人格补充规格书。
        要求：自然语言、覆盖多角度（角色/语气/共情/禁忌/关键事件记忆等）、
        与已有画像一致、不矛盾、不超 200 字。
user:
  - 现有 PersonaSpec（若有）
  - 当前 L3 权重快照
  - 热记忆窗口（doc/07）+ 冷记忆 top-K 检索
  - 历轮 turn_summary 链（doc/07，≤100 字×N）
→ 结构化输出（见 §2）
```

要点：

- **输入是"历史提炼物"而非原始消息流**：优先喂 `turn_summary` 链与记忆检索结果，降低用户提示注入污染 PersonaSpec 的风险（见 §7）。
- **`persona_spec` 硬上限 200 字**（中文按字符计）；超出由解析器**截断并告警**，绝不让超长文本注入 Prompt。
- `confidence < DLA_PERSONA__MIN_CONFIDENCE`（默认 0.7）时整体丢弃，不落地。

## 5. 冲突校验：补充的人格不能冲突

落地前过三道一致性闸门：

1. **与现有结构化 L3 一致性**：若 `persona_spec` 隐含"严厉/冷淡"，但当前 `agent_tone.gentle` / `empathy` 权重高，判定为**方向冲突** → 进入 `DLA_PERSONA__CONFLICT_POLICY` 处理（`review`=进队列不覆盖 / `discard`=丢弃该方向）。
2. **与历史 PersonaSpec 自洽**：类似 doc/02 §11.4 的 `redundancy_with`，检测"既说活泼又说冷淡"这类**自我矛盾**，冲突时保留高置信侧。
3. **安全硬约束不可撼动**：`persona_spec` 若隐含突破 `constraint.safe_mode`（doc/09 §6）的内容，**直接丢弃该片段**并记录 warn——安全底线高于演进。

`conflicts_with` 自检可由推演 LLM 同时输出，与规则引擎交叉验证。

## 6. 落地与注入

- PersonaSpec 作为 L3 人格段的一段**补充文本**注入 Prompt（doc/02 §7.2 段落③"你的人格"之后、用户段之前，或以独立"【人格补充】"段），与结构化 L3 关键词**并存互补、互不替换**。
- 仍走 doc/02 §7.4 的稳定性机制：重建后计算 L3 的 `Δ`，低于 `τ_rebuild` 沿用、超过 `τ_notify` 时**主动说明**（如"我好像更懂你了，之后会稍微……"），让演进对用户可见、可感知。
- 存储：新增 `persona_spec` 表（见 §9），记录版本/触发轮次/置信度/来源摘要；支持 `dla persona show` / `dla persona rollback --version <n>`。
- **透明可解释**：UI 权重面板/调试思维链中以 `PersonaSpec` 帧展示本次推演的输入摘要、冲突判定与落地结果（与 doc/04 §2.3 一致）。

## 7. 安全阀（默认关 + 多重护栏）

| 护栏 | 说明 |
|---|---|
| 默认关闭 | `DLA_PERSONA__AUTO_UPDATE=false`，需显式开启才生效 |
| 高门槛触发 | §3 五条件全满足才推演 |
| 冲突不覆盖 | 冲突走 review/discard，绝不静默覆盖既有画像 |
| 安全不可破 | `safe_mode` 硬约束优先级高于演进 |
| 注入隔离 | PersonaSpec 为受限"补充"段，不进入耦合规则、不影响权重公式 |
| 提示注入缓解 | 输入以 `turn_summary` 链 + 记忆检索为主，非原始消息流 |
| 可回滚 | 每次重建留版本，用户/开发者可一键回退 |
| 可观测 | 全程落 `chain_log`，事后可复盘任意一次演进"为什么" |

## 8. 与既有模块关系

- **与 §11.6 规则建议**：互补而非替代。规则仍只进建议池、人工批准；PersonaSpec 是"软画像"通道，二者并行不悖。
- **与 doc/07 记忆**：直接消费热/冷记忆与 `turn_summary` 链作为输入源。
- **与 doc/06 在线学习**：LVM 负责向量空间的关联学习（经 γ 影响 L3 先验）；PersonaSpec 是**可读、可编辑的自然语言层**，二者互补——一个管"隐性关联"，一个管"显性画像"。
- **与 doc/09 预设模板**：PersonaSpec 是**会话级、累积演进**的，叠加在模板的 `l3_baseline` 之上；切换场景/新建会话重置。

## 9. 存储草图（实现期细化进 doc/03）

```sql
CREATE TABLE persona_spec (
  id          INTEGER PRIMARY KEY,
  session_id  TEXT NOT NULL,
  version     INTEGER NOT NULL,
  spec_text   TEXT NOT NULL,                 -- persona_spec，≤200 字
  covers      TEXT,                          -- JSON 数组
  confidence  REAL,
  source_turn INTEGER,
  conflict_policy TEXT,                      -- 本次冲突处理策略
  created_at  TEXT NOT NULL
);
```

## 10. 配置约定（doc/01 §8 增补）

```bash
# ---- 人格演进·受控自动补充（doc/10）----
DLA_PERSONA__AUTO_UPDATE=false          # 默认关；开后才允许 LLM 依历史自动推演人格规格（苛刻门槛）
DLA_PERSONA__MIN_TURNS=12               # 触发最少轮次（远超冷启动/周期）
DLA_PERSONA__MIN_EVIDENCE=5.0           # 用户参与度 evidence 下限，确保对话有实质内容
DLA_PERSONA__COOLDOWN_TURNS=8           # 两次重建最小轮次间隔
DLA_PERSONA__SPEC_MAX_CHARS=200         # persona_spec 硬上限（中文按字计）
DLA_PERSONA__MIN_CONFIDENCE=0.7         # 推演置信度下限，低于则丢弃
DLA_PERSONA__CONFLICT_POLICY=review     # conflict 时：review(进队列不覆盖) | discard
```
