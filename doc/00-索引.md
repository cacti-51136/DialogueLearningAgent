# DialogueLearningAgent 设计方案 · 索引

> 目标：一个**基于关键词分析与提示**的对话 Agent。它的与众不同之处在于——驱动对话的 Prompt 不是写死的，而是由**三层带权重的关键词**实时推导出来的，并且会随对话进程自我调整。

## 一句话理解这个项目

用户在说话的同时，系统在后台回答三个问题：

1. **这是什么样的对话？**（功能场景层 L1）
2. **对面这个人现在是什么状态？**（用户肖像层 L2）
3. **那么我此刻应该扮演一个什么样的交流对象？**（Agent 肖像层 L3）

第三个问题的答案，就是当轮真正喂给大模型的 System Prompt。

## 三层模型速览

```
┌──────────────────────────────────────────────────────────┐
│  L1 功能场景层  Functional Scenario                       │
│  这场对话是关于什么的？双方各自想要什么？                   │
│  例：场景=英语口语练习 / Agent目标=引导开口 / 用户目标=流利度 │
│  特征：相对稳定，多由用户显式选择或模板注入，权重最高        │
└────────────────────────┬─────────────────────────────────┘
                         │ 约束候选空间
                         ▼
┌──────────────────────────────────────────────────────────┐
│  L2 用户肖像层  User Portrait                             │
│  对面是谁？他现在状态如何？                                │
│  预设项：职业、母语、兴趣、学习目标                        │
│  观察项：情绪、知识水平、偏好、卡点、注意力（对话中分析得出）│
│  特征：动态演化，带置信度与时间衰减                        │
└────────────────────────┬─────────────────────────────────┘
                         │ 调节取值（耦合规则 + 可选 LLM 精炼）
                         ▼
┌──────────────────────────────────────────────────────────┐
│  L3 Agent 肖像层  Agent Persona                           │
│  那么我应该是什么样的人来跟他聊？                          │
│  例：角色=耐心的外教 / 语气=温和幽默 / 纠错=延时纠错        │
│       / 语言复杂度=A2 / 主动性=高 / 共情度=高              │
│  特征：不由输入直接给出，而是由 L1 × L2 推导出来的"应然"    │
└────────────────────────┬─────────────────────────────────┘
                         │ 加权渲染 + 预算裁剪
                         ▼
                  System Prompt（当轮生效）
```
